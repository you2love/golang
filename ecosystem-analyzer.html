go-critic

简介

go-critic 是一个可扩展的 Go 源代码分析器，提供了大量代码质量检查规则，可以识别代码中的坏味道和潜在问题。

安装和使用

# 安装
go install github.com/go-critic/go-critic/cmd/gocritic@latest

# 运行检查
gocritic check ./...

# 运行特定检查
gocritic check -enable=rangeExprCopy,typeDefFirst ./...

# 列出所有检查
gocritic doc

# 查看特定检查文档
gocritic doc rangeExprCopy

检查规则分类

分类 说明 示例检查
diagnostic 诊断检查 detects bugs
style 代码风格 code style issues
performance 性能优化 performance issues
experimental 实验性检查 experimental rules
opinionated 主观建议 opinionated rules

配置文件

📝 .gocritic.yaml 配置

# .gocritic.yaml
enabled-tags:
  - diagnostic
  - style
  - performance

disabled-checks:
  - regexpMust
  - appendAssign

settings:
  # hugeParam 设置
  hugeParam:
    sizeThreshold: 80
  # rangeExprCopy 设置
  rangeExprCopy:
    sizeThreshold: 512
  # typeDefFirst 设置
  typeDefFirst:
    ignoreTests: true

gosec

简介

gosec (Go Security) 是一个 Go 源代码安全扫描器，通过检查 AST 来识别潜在的安全漏洞。

安装和使用

# 安装
go install github.com/securego/gosec/v2/cmd/gosec@latest

# 运行扫描
gosec ./...

# 排除特定规则
gosec -exclude=G101,G104 ./...

# 输出为 JSON
gosec -fmt=json -out=results.json ./...

# 输出为 SARIF (用于 GitHub)
gosec -fmt=sarif -out=results.sarif ./...

# 包含测试文件
gosec -tests ./...

安全规则

规则 ID 说明 示例
G101 硬编码凭证 密码、API key
G102 绑定到所有接口 0.0.0.0
G103 使用 unsafe 包 unsafe.Pointer
G104 未检查错误 忽略 error
G106 SSH 禁用主机检查 InsecureIgnoreHostKey
G107 URL 注入 http.Get(userInput)
G108 命令注入 exec.Command(userInput)
G109 XML 解析漏洞 xml.Unmarshal
G110 Zip 炸弹 zip.NewReader
G201 SQL 注入 SQL 拼接
G202 SQL 注入 SQL 格式化
G301 文件权限过大 os.OpenFile 0777
G302 文件权限过大 os.Chmod 0777
G304 文件路径遍历 os.Open(userInput)
G401 弱加密算法 MD5, SHA1
G402 TLS 配置不当 MinVersion 过低
G403 弱 RSA 密钥 <2048 位
G501 弱加密算法 crypto/md5
G502 弱加密算法 crypto/des
G503 弱加密算法 crypto/rc4
G504 导入黑名单 crypto/md5
G505 弱加密算法 crypto/sha1
G601 隐式内存别名 range 变量引用

GitHub Actions 集成

# .github/workflows/security.yml
name: Security Scan

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  gosec:
    name: gosec
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - uses: actions/setup-go@v4
        with:
          go-version: '1.21'
      
      - name: Run Gosec Security Scanner
        uses: securego/gosec@master
        with:
          args: ./...

gocyclo

简介

gocyclo 计算 Go 代码的圈复杂度 (Cyclomatic Complexity)，帮助识别过于复杂的函数。

安装和使用

# 安装
go install github.com/fzipp/gocyclo/cmd/gocyclo@latest

# 运行分析
gocyclo ./...

# 设置阈值
gocyclo -over 15 ./...

# 输出前 10 个复杂函数
gocyclo -top 10 ./...

# 输出平均复杂度
gocyclo -avg ./...

圈复杂度说明

复杂度 评级 建议
1-5 简单 易于理解和维护
6-10 中等 可以考虑简化
11-20 复杂 建议重构
21-50 非常复杂 需要重构
>50 不可测试 必须重构

gocognit

简介

gocognit 计算 Go 代码的认知复杂度 (Cognitive Complexity)，比圈复杂度更能反映代码的理解难度。

安装和使用

# 安装
go install github.com/uudashr/gocognit/cmd/gocognit@latest

# 运行分析
gocognit ./...

# 设置阈值
gocognit -over 25 ./...

# 输出前 N 个复杂函数
gocognit -top 20 ./...

集成使用

在 golangci-lint 中使用

# .golangci.yml
linters:
  enable:
    # 代码分析
    - gocritic
    - gocyclo
    - gocognit
    - unconvert
    - ineffassign
    - unparam
    - prealloc
    # 安全检查
    - gosec
    # 错误检查
    - errcheck
    - errorlint
    # 资源检查
    - bodyclose
    - rowserrcheck
    - sqlclosecheck
    # 其他
    - misspell
    - predeclared
    - asciicheck

linters-settings:
  gocyclo:
    min-complexity: 15
  gocognit:
    min-complexity: 25
  gosec:
    excludes:
      - G101
      - G104
