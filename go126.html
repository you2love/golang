🆕 语言层面更新

✨

new() 表达式增强

new() 函数现在可以直接接受表达式作为初始值

ptr := new(int64(300))
🔄

自引用泛型

泛型类型可以引用自身，实现递归约束

type Adder[A Adder[A]]

new() 函数增强示例

package main

import "encoding/json"

type Config struct {
    MaxRetries *int `json:"max_retries,omitempty"`
    Timeout    *int     `json:"timeout,omitempty"`
}

// Go 1.26 简化写法
func newConfig() Config {
    return Config{
        MaxRetries: new(3),
        Timeout:    new(30),
    }
}

// JSON 序列化
func main() {
    c := newConfig()
    data, _ := json.Marshal(c)
    fmt.Println(string(data))
}

自引用泛型示例

// 递归类型约束 - Go 1.26 新特性
type Node[T Node[T]] interface {
    Value() T
    Children() []Node[T]
}

// 使用自引用泛型
type Tree[T any] struct {
    Value    T
    Children []Tree[T]
}

// 递归计算
func Sum[T any](t Tree[T]) T {
    var total T = t.Value
    for _, child := range t.Children {
        total += Sum(child)
    }
    return total
}

实验性 SIMD 示例

// 需要 GOEXPERIMENT=simd
package main

// 使用 simd/archsimd 进行向量运算
func VectorAdd(a, b []float32) []float32 {
    result := make([]float32, len(a))
    
    // 使用 SIMD 指令加速
    for i := 0; i < len(a); i += 8 {
        va := archsimd.LoadF32x8(a[i:])
        vb := archsimd.LoadF32x8(b[i:])
        vc := archsimd.AddF32x8(va, vb)
        archsimd.StoreF32x8(result[i:], vc)
    }
    
    return result
}

🚀 迁移指南

从 Go 1.25 迁移

  1. 运行 go mod tidy 更新依赖
  2. 运行 go fix ./... 自动现代化代码
  3. 测试新特性：GOEXPERIMENT=simd go test
  4. 如有问题可使用 GOEXPERIMENT=nogreenteagc 禁用 Green Tea GC

注意事项

  • Green Tea GC 的 opt-out 选项将在 Go 1.27 中移除
  • 如果遇到问题请提交 issue
  • 推荐使用 go 1.25.0 作为模块最低版本以确保兼容性
