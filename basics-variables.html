变量

变量是程序中用于存储数据的基本单位。Go 语言提供了多种声明变量的方式，让我们学习如何高效地使用它们。

📌 变量定义的四种方式

Go 语言提供了四种声明变量的方式，选择合适的方式可以让代码更简洁、更易读。

变量声明方式

变量声明方式对比
方式 语法 示例 适用场景
var 关键字 var name type var name string 需要明确类型或零值初始化
短变量声明 name := value name := "Go" 函数内部，类型可推断
批量声明 var (name1, name2 type) var (x, y int) 声明多个同类型变量
零值初始化 var name type = value var name string = "" 明确初始化值

代码示例

1. 基础变量声明

package main

import "fmt"

func main() {
    // 方式1：使用 var 关键字
    var name string = "Go 语言"
    fmt.Println("名字:", name)

    // 方式2：短变量声明（函数内）
    age := 10
    fmt.Println("年龄:", age)

    // 方式3：类型推断
    var height = 1.75
    fmt.Printf("身高: %.2f 米\n", height)
}

2. 批量声明变量

package main

import "fmt"

func main() {
    // 批量声明不同类型
    var (
        name   string  = "张三"
        age    int     = 25
        height float64 = 1.75
        isMale bool    = true
    )

    fmt.Printf("姓名: %s, 年龄: %d, 身高: %.2f, 性别: %t\n", 
        name, age, height, isMale)
}

3. 多变量赋值

package main

import "fmt"

func main() {
    // 交换两个变量的值
    a, b := 1, 2
    fmt.Printf("交换前: a=%d, b=%d\n", a, b)
    
    a, b = b, a
    fmt.Printf("交换后: a=%d, b=%d\n", a, b)

    // 函数返回多值
    sum, diff := calculate(10, 5)
    fmt.Printf("和: %d, 差: %d\n", sum, diff)
}

func calculate(a, b int) (int, int) {
    return a + b, a - b
}

浮点数

float32, float64

var f float64 = 3.14
✅

布尔值

true 或 false

var b bool = true

零值

什么是零值？

Go 语言中，变量声明时如果没有显式初始化，会自动赋值为该类型的零值。

各类型的零值
类型 零值 示例
int, int8, int16, int32, int64 0 var n int // n = 0
uint, uint8, uint16, uint32, uint64 0 var n uint // n = 0
float32, float64 0.0 var f float64 // f = 0.0
bool false var b bool // b = false
string "" (空字符串) var s string // s = ""
pointer, slice, map, channel nil var p *int // p = nil

⚠️ 注意事项

  • 未初始化的指针使用会导致 panic
  • 零值 nil 与空字符串 "" 是不同的
  • nil slice 可以安全使用，但 nil pointer 不行

最佳实践

✅ 推荐做法

  • 函数内部：使用短变量声明 :=
  • 需要零值：使用 var 声明
  • 批量声明：使用 var () 语法
  • 命名规范：使用驼峰命名法（camelCase）

package main

import "fmt"

func main() {
    // 推荐做法示例
    
    // 1. 函数内使用短变量声明
    if err := doSomething(); err != nil {
        fmt.Println("Error:", err)
        return
    }
    
    // 2. 需要零值时使用 var
    var counter int  // counter = 0
    
    // 3. 批量声明相关变量
    var (
        userName  string
        userEmail string
        userAge   int
    )
    
    // 4. 有意义的变量名
    var maxRetryCount = 3
    var isActive = true
}

func doSomething() error {
    return nil
}
